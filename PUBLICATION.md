# Publication notes

Transect Navigator is being preserved as a public-source candidate.

Current scope: QGIS survey preparation, GPS deviation and QA/QC; substantial source, fixtures and documentation. README records 460 offscreen tests for v0.2 and 283 for the separate v0.1 baseline; these were not rerun.

Preparation still required: Resolve the LICENSE placeholder, which explicitly says private evaluation only. Keep v0.2 labeled development; its interactive GUI validation is outstanding. Use one main repository, with v0.1 preserved deliberately rather than publishing duplicate folders.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.
