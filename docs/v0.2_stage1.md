## Minimal compatibility seam

`integration/survey.py` accepts a nonblank Survey_ID and one existing IngestionResult whose recording has already been explicitly accepted for its one planned feature. It delegates unchanged to comparison, statistics and event services. The result envelope carries survey identity, the original ingestion result and the three legacy result objects. No Survey_ID fields are injected into legacy layers or exports.

The caller supplies acceptance; this API does not infer it. It does not import files, filter observations, assign membership, publish layers or change UI. Existing geometry/CRS guards remain authoritative. There is no multi-transect orchestration or persistent survey data model yet.
