# Focused Stage 5 reviewed-QA fixture

This fixture is generated by `tools/survey_qa_fixture.py`, which intentionally imports
no Transect Navigator production code. Coordinates use direct equatorial WGS84
construction. Expected offsets, statistics, path lengths, event values and reviewer
membership are closed-form, hand-authored oracle values in `expected.json`.

Contents:

- `planned.geojson`: two east-directed 100 m planned transects;
- `A.csv`: full T01 forward Visit with a sustained deviation, transition fixes,
  full T02 reverse Visit, ambiguous fixes and one unrelated fix;
- `B.csv`: partial T01 Visit from station 0 to 60 m;
- `C.csv`: partial reverse T01 Visit from station 100 to 50 m;
- `expected.json`: exact dispositions and independently calculated QA answers.

Expected intake/review totals are 40 raw observations: 35 assigned, 2 ambiguous and
3 unassigned, including 2 transitions. Four accepted Visits produce the numeric
results documented in `docs/v0.2_stage5.md`. Removing the full T01 Visit leaves two
complementary partial Visits whose accepted track lengths total 110 m while unioned
support is correctly capped at 100 m.

Regenerate and test from the repository:

```shell
python3 -m tools.survey_qa_fixture
python3 -m unittest tests.test_survey_qa tests.qgis.test_survey_qa
```

The generated recordings contain no Transect_ID labels. Tests apply the independent
review decisions by exact source row identity, then verify production QA output against
the oracle. This focused fixture does not replace SYN01 or the future 12-transect
Stage 8 acceptance survey.
